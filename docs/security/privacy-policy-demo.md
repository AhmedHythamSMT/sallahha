# Privacy policy (DEMO draft — not legal advice)

Sallahha FieldOps demo collects: name, phone, address/governorate, optional map pin, request photos, job notes — only to run maintenance requests. Stored locally on device in the demo; if an optional cloud backend is configured, data syncs to that project. No sale of data. No card data collected (mock payments). Notifications show generic text ("Request #123 updated") without address details. Photos stay scoped to the job. Retention: demo data deletable via Admin → Reset demo data; pilot data retained ≤12 months unless deletion requested. To request deletion in a pilot, contact the shop owner/admin. Consent: creating a request or accepting a job counts as consent for that job's operational data; location/photo are optional and skippable. No formal compliance claimed.
